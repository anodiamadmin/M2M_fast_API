# M2M_fast_API
Authentication APIs built for microservices for micro2move iOS app.

# Developers' Guide
Install Python 3.11.9

Run:
```bash
python3.11 -m venv .venv
```
to create a virtual environment with python 3.11.9

Run:
```bash
.venv\Scripts\Activate.ps1
```
to activate the .venv (if it's not active already)

Run:
```bash
pip install -r  requirements.txt
```
to install all the project requirements

# You are ready to code!
